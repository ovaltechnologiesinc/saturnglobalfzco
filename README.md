# Saturn Global FZCO

Official web application for **Saturn Global FZCO**, a premier physical gold trading, bullion brokerage, and precious metals services company headquartered in Dubai, UAE.

---

## Overview

Saturn Global FZCO provides physical precious metals trading and brokerage services, connecting primary gold producers, miners, and institutional market participants worldwide through Dubai's global gold market.

### Core Operations
* **Physical Gold Bullion Trading & Brokerage**
* **Assaying, Testing & Refining Coordination**
* **Secure Vault Storage & Global Armored Logistics**
* **Mining Operations Support & Project Partnership**

---

## Tech Stack

* **Frontend**: React 18, TypeScript, Vite
* **Styling**: Tailwind CSS
* **Routing**: TanStack Router
* **Animations**: Framer Motion
* **Icons**: Lucide React

---

## Development

### Prerequisites
* Node.js (v18+)
* npm

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
